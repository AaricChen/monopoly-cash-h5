# Monopoly Cash H5

单设备本地多人（Pass & Play）H5 版经典桌游《大富翁》（Monopoly）。核心差异化是**真实纸币找补与结算**：数字版不自动扣款，玩家需像实体桌游一样凑钞、找零，兼顾娱乐、教育与心算练习。
