# Pass & Play 与 UI 布局

## 同屏多人原则

仅一台设备，无网络；当前操作者视为「持有人」，其他人应物理上不看屏幕或等待交接。

## 回合交替（Pass & Play Flow）

### 设备转移遮罩

在以下时机弹出**全屏遮罩**（不可跳过，可配置仅在有「秘密信息」时启用）：

- 回合结束（掷骰、移动、交易、建房等全部完成）
- 从玩家 A 切换到玩家 B

遮罩文案示例：

> 请将设备递给 **玩家 B（红 · 帽子）**  
> [ 我准备好了 ]

点击确认后再渲染 B 的完整视角（手牌、现金、可操作的秘密卡）。

### 当前玩家标识

- 每位玩家：主色（红 / 蓝 / 黄 / 绿）+ 棋子造型（帽子、小狗、汽车、赛车等）。
- 当前回合：棋盘边框、顶栏/底栏高亮、轻微光效动画。

### 信息可见性

| 信息类型 | 他人回合是否可见 |
|----------|------------------|
| 棋盘公有信息（归属、房屋数） | 可见 |
| 当前玩家现金张数 | 仅当前玩家 |
| 机会/命运手持卡、未使用免罪卡 | 仅当前玩家 |
| 交易谈判中间态 | 参与双方回合内可见 |

## 布局策略

### 棋盘主视图

- **推荐**：自适应缩放的 2D 环形棋盘，或轻量 2.5D 鸟瞰。
- **中心区**：动态信息区 — 掷骰、抽卡、交易/找零面板、简短事件 log。

### 资产抽屉

- 默认折叠在屏幕边缘（底栏或侧栏）。
- 展开内容：地产权证（Deed Cards）、各面额纸币、抵押状态摘要。

### Phone vs Tablet

| 要素 | 手机 | 平板 |
|------|------|------|
| 棋盘 |  pinch 缩放 + 聚焦当前棋子 | 一屏展示更多格 |
| Wallet Panel | 全屏或 bottom sheet | 侧边抽屉 + 棋盘并排 |
| 找零 | 分步：先支付区，再全屏找零 | 支付区与找零区同屏 |

## 关键动效（Phase 3，文档预置）

- 骰子：CSS/Canvas 或轻量 3D 物理感
- 棋子移动：沿格点路径 tween
- 卡牌：翻转动画
- 纸币：拖拽阴影、落位音效（optional）

## 无障碍与可读性

- 色盲模式：棋子形状 + 图案区分，不仅依赖颜色。
- 大 tap 区域：纸币拖拽热区 ≥ 44pt。
- 金额字体：等宽数字，差额/找零用对比色强调。
