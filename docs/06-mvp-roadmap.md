# MVP 路线图

## Phase 1 — 核心原型

**目标**：验证「棋盘 + 纸币凑钞/找零 + 双人轮流」闭环。

### 范围

- [ ] 40 格棋盘数据与 2–4 玩家棋子移动
- [ ] 回合 FSM：`ROLL_DICE` → `MOVE` → `LAND` → 买地或付租 → `END_TURN`
- [ ] 基础 Wallet Panel：凑钞支付、简单找零（银行为收款方）
- [ ] Pass & Play 交接遮罩（最小文案）
- [ ] localStorage 单槽存档

### 不在此阶段

- 机会/命运全卡池、监狱、建房、拍卖、抵押

### 完成定义

- 两名玩家可从头玩到有人现金耗尽（可手动宣告胜负）
- 一笔 $140 级支付 + $360 找零在练习模式下可完成且错算有提示

---

## Phase 2 — 完整规则

**目标**：接近家庭版 Monopoly 可玩度。

### 范围

- [ ] 同色组建房与房屋库存枯竭
- [ ] 机会 / 命运完整卡池与效果
- [ ] 入狱 / 出狱（保释金、出狱卡、掷双）
- [ ] 抵押、变卖房屋、拍卖（无人买地）
- [ ] 破产与资产转移
- [ ] 娱乐模式：一键凑钞 / 找零提示

### 完成定义

- 标准 4 人局可玩至剩 1 人；破产路径经纸币流程无死锁

---

## Phase 3 — 体验与 polish

**目标**：接近商业 H5 质感。

### 范围

- [ ] 骰子/卡牌/纸币动效与音效
- [ ] 平板与手机 responsive 完善
- [ ] 胜利结算、对局统计（心算错误次数等）
- [ ] IndexedDB 多存档、导出/导入 JSON
- [ ] PWA 离线包

### 完成定义

- 内测用户「找零不烦躁」主观评分达标（可自建小问卷）
