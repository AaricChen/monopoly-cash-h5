# 经典机制还原

目标：保持「原本的味道」，数字化时优先**规则忠实** + **纸币结算接入**。

## 机制对照表

| 经典机制 | H5 实现建议 |
|----------|-------------|
| 骰子 | 3D 或 CSS3/Canvas 动画；双数（Double）额外回合；连续三次双数进监狱 |
| 机会 / 命运 | 经典卡池；翻卡动画；涉及金额时走 [纸币与结算系统](02-cash-settlement-system.md) |
| 地产与建房 | 同色组集齐后解锁建房；绿屋/红屋（酒店）数量全局有限 — 「房屋枯竭」 |
| 破产与抵押 | 现金不足时强制抵押/变卖；须凑齐纸币结清；仍不足则破产，资产归债权人 |

## 骰子与移动

- 回合开始：`ROLL_DICE` → 出点数 → 沿棋盘移动。
- **Double**：同一玩家再掷一次（状态机回到 `ROLL_DICE`，标记 `extraTurnFromDouble`）。
- **三连续 Double**：直接送监狱，结束连续掷骰特权。

## 地块 landing 处理

落点类型（示意，实现时以标准 Monopoly 40 格为准）：

- GO / 税收 / 机会 / 命运 / 入狱 / 免费停车 / 地产 / 公用事业 / 铁路等。

地产：

- 无主 → 提示购买（银行拍卖为 Phase 2）。
- 有主 → 计算租金（含房屋档位）→ 触发支付 + 找零流程。

## 机会卡 / 命运卡

- 维护独立洗牌堆 + 弃牌堆（可选：弃牌洗回）。
- 卡面类型：移动、收支、全局事件、出狱卡等。
- 任意「支付 / 收取固定金额」必须经钱包 UI，而非静默改余额。

## 同色组与房屋

- `ColorGroup` 集齐且未抵押 → 允许在组内地产建房。
- 全局 `housesRemaining` / `hotelsRemaining` 计数；为 0 时禁止新建。
- 售房/降级：纸币回流规则需与官方一致（售价半数等），售房所得进入玩家钱包张数（娱乐模式可自动拆面额）。

## 监狱

- 进狱：三 Double、落在「进狱」格、部分卡面。
- 出狱：掷双、交保释金（纸币流程）、使用出狱卡。

## 抵押与破产

### 抵押

- 玩家主动或**强制**（付不起时）进入抵押 UI。
- 抵押所得现金以纸币形式加入钱包（系统可生成银行面额组合）。
- 赎回：支付赎回价 + 利息，走凑钞流程。

### 破产

1. 尝试：变卖房屋 → 抵押 → 凑钞支付。
2. 仍无法支付 → 宣告破产。
3. 资产转移：债权人（玩家或银行）按规则接收地产、剩余现金等。
4. 仅剩一名未破产玩家 → 胜利流程。

## 胜利条件

- 最后一名未破产玩家获胜；或可选「限时最高分资产」变体（非 MVP）。

## 规则配置（建议）

单局创建时可 toggles：

- 练习 / 娱乐结算模式
- 银行纸币无限
- 拍卖规则开/关（Phase 2）
- 初始现金与 Pass GO 金额（经典 $1500 / $200）
